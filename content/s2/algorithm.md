## 한 줄 정의

알고리즘(Algorithm)은 주어진 작업을 수행하는 명령어를 순서대로 나열한 절차이고, 시간 복잡도는 그 절차의 수행 시간이 입력 크기에 따라 어떻게 늘어나는지를 나타낸 값이다.

## 왜 시험에 나오나

2과목 상위 출제군이다. 표기법 하나의 뜻을 묻거나, 설계 기법 목록에 없는 것을 고르게 하거나, 검색 알고리즘의 전제 조건을 뒤집어 놓는 세 각도로 나온다.

## 핵심

| 설계 기법 | 방식 |
|---|---|
| 분할 정복 | 문제를 작은 문제로 나눠 풀고 합친다 |
| 탐욕 | 현재 시점에서 가장 좋아 보이는 것을 고른다 |
| 백트래킹 | 해가 아니면 되돌아가 다른 가지를 시도한다 |

- O(1)은 수행 시간이 입력 데이터 수와 관계없이 일정하다는 뜻이다.
- 선형 검색은 처음부터 하나씩 비교하므로 자료가 정렬돼 있지 않아도 된다.
- 이진 검색은 자료가 정렬돼 있어야 하고, 비교할 때마다 대상이 절반으로 줄어든다.
- 피보나치 검색은 피보나치 수열로 다음 비교 대상을 정한다. 이진 검색과 다른 알고리즘이다.

## 헷갈리는 지점

- 정렬을 전제로 하는 검색은 이진 검색이다. 선형 검색이 정렬을 요구한다는 서술은 오답이다. 두 설명을 맞바꾼 보기가 반복된다.
- 피보나치 수열로 비교 대상을 정한다는 서술을 이진 검색 설명에 붙여 놓는다. 이진 검색과 피보나치 수열은 관계가 없다.
- O(1)은 입력 데이터가 한 개라는 뜻이 아니다. 입력 수와 무관하게 시간이 일정하다는 뜻이다.
- 설계 기법을 묻는 문항에는 정적 블록(Static Block)처럼 알고리즘 설계와 무관한 이름이 하나 섞인다.

## 기출 패턴

복잡도 문항은 표기 하나를 주고 뜻을 고르게 하거나, 반대로 O(n log₂n)에 해당하는 정렬을 고르게 한다. 검색 문항은 이진 검색의 설명 넷 중 하나만 피보나치 검색 설명으로 바꿔 틀린 것을 찾게 한다. 설계 기법 문항은 분할 정복·탐욕·백트래킹을 참으로 깔고 존재하지 않는 기법 하나를 넣는다.

## 퀴즈
- q: 시간 복잡도 O(1)의 뜻으로 맞는 것은?
  choices: [입력 데이터가 한 개다, 수행 시간이 입력 수와 무관하게 일정하다, 컴퓨터로 처리할 수 없다, 알고리즘 길이가 입력보다 짧다]
  a: 2
  why: O 표기는 입력 크기에 따른 증가율을 나타내므로 O(1)은 시간이 일정하다는 뜻이다. 입력 데이터가 한 개라는 것은 자료의 개수일 뿐 복잡도와 무관하다.
- q: 검색을 수행하기 전에 자료가 정렬돼 있어야 하는 알고리즘은?
  choices: [선형 검색, 순차 검색, 이진 검색, 완전 탐색]
  a: 3
  why: 이진 검색은 중앙값과 비교해 범위를 반으로 줄이므로 정렬이 전제다. 선형 검색은 앞에서부터 하나씩 비교하므로 정렬 여부와 상관없다.
- q: 알고리즘 설계 기법으로 거리가 먼 것은?
  choices: [분할 정복, 탐욕, 정적 블록, 백트래킹]
  a: 3
  why: 정적 블록은 알고리즘 설계 기법이 아니다. 백트래킹은 해가 아닌 경로에서 되돌아가 다시 시도하는 실재하는 설계 기법이다.
