## 한 줄 정의

신기술 문항은 용어 하나의 정의를 서술로 주고 이름을 고르게 하는 어휘 문제다.

## 왜 시험에 나오나

5과목에서 가장 많은 서로 다른 용어가 등장하는 자리다. 이해할 것이 없고 이름과 설명을 짝지어 두면 그대로 풀린다.

## 핵심

| 용어 | 설명 |
|---|---|
| 하둡 Hadoop | 오픈 소스 기반 분산 컴퓨팅 플랫폼, 빅데이터 저장과 처리 |
| MapReduce | 대용량 데이터 분산 처리를 위한 프로그래밍 모델 |
| Sqoop | 하둡과 관계형 데이터베이스 사이의 데이터 전송 도구 |
| 타조 Tajo | 하둡 기반 분산 데이터 웨어하우스, 국내 주도 |
| 데이터 마이닝 | 대량 데이터에서 변수 간 관계와 패턴을 찾는 기법 |
| 디지털 트윈 | 물리적 사물을 가상 모델로 복제해 시뮬레이션 |
| 디지털 아카이빙 | 디지털 자원을 장기 보존하는 작업 |
| MQTT | 발행 구독 방식의 경량 메시징 프로토콜, IoT용 |
| SDN | 네트워크를 제어부와 데이터 전달부로 분리 |
| 메시 네트워크 | 대규모 디바이스 연결에 최적화된 무선 네트워크 |
| 도커 Docker | 컨테이너 응용 프로그램 배포를 자동화하는 엔진 |
| BaaS | 블록체인 개발 환경을 클라우드로 제공 |
| PaaS-TA | 국내 개발 개방형 클라우드 컴퓨팅 플랫폼 |
| 허니팟 Honeypot | 침입자를 유인해 공격 기법을 수집하는 미끼 시스템 |
| 스마트 그리드 | 정보 통신 기술을 접목한 지능형 전력망 |
| OWASP | 웹 취약점과 악성 코드를 연구하는 비영리 단체 |
| 비컨 Beacon | 블루투스 기반 근거리 무선 통신 장치 |
| 포스퀘어 | 위치 기반 소셜 네트워크 서비스 |

## 헷갈리는 지점

- 하둡은 플랫폼이고 MapReduce는 처리 모델이다. 두 이름이 같은 문항의 보기로 함께 깔린다.
- OWASP는 기술이 아니라 단체다. 블록체인이나 양자 키 분배로 설명한 보기는 오답이다.
- 허니팟은 취약해 보여야 한다. 공격자에게 노출되지 않도록 숨긴다는 서술은 방향이 반대다.
- MQTT를 묻는 문항에 MLFQ가 오답으로 붙는다. MLFQ는 스케줄링 기법이다.
- 디지털 트윈과 디지털 아카이빙은 이름만 닮았다. 앞은 가상 복제, 뒤는 장기 보존이다.

## 기출 패턴

점 세 개짜리 설명 목록을 주고 용어를 고르게 하는 형식이 고정돼 있다. 오답 보기에는 철자만 비슷하고 분야가 다른 이름을 넣는다. 하둡 문항의 오답은 비컨·포스퀘어·맴리스터로 여러 회차에서 동일하게 반복된다. 클라우드 서비스 구분은 IaaS·PaaS·SaaS·BaaS 넷을 한 문항에서 섞는다.

## 퀴즈
- q: 하둡과 관계형 데이터베이스 사이의 데이터 전송을 위해 설계된 도구는?
  choices: [Sqoop, Tajo, MapReduce, Docker]
  a: 1
  why: Sqoop이 하둡과 관계형 데이터베이스를 잇는 전송 도구다. 타조는 하둡 기반 데이터 웨어하우스라 전송 역할이 아니다.
- q: 네트워크를 제어부와 데이터 전달부로 분리해 소프트웨어로 관리하는 기술은?
  choices: [NFS, SDN, Network Mapper, AOE Network]
  a: 2
  why: 제어부와 전달부 분리가 SDN의 정의다. NFS는 원격 파일 시스템 공유라 제어 평면과 무관하다.
- q: 침입자를 속여 공격 기법 정보를 수집하려고 일부러 설치하는 시스템은?
  choices: [Apache, Hadoop, Honeypot, MapReduce]
  a: 3
  why: 미끼 역할을 하는 시스템이 허니팟이다. 하둡은 분산 컴퓨팅 플랫폼이라 침입 유인과 관계가 없다.
